# Internationalization (i18n) Rules

## Core Rule: 100% i18n by Default
For all new implementations and modifications (views, dialogs, modals, cards, tables, inputs, alerts, tooltips, validation messages, and notifications):
1. **Never hardcode user-facing strings**: All text must be rendered through `vue-i18n` using `t('...')` or `$t('...')`.
2. **Strict 1:1 Locale Key Parity**: Any key added to `client/src/locales/en.json` MUST also be added to `client/src/locales/uk.json` with a precise, high-quality translation (and vice versa). Key hierarchies and total counts must match with zero discrepancies.
3. **Structured Namespaces**: Group keys into dedicated feature/dialog namespaces (e.g. `importComponentsModal`, `componentDetailsModal`, `produceModal`) or common namespaces (`common`, `dialogs`).
4. **Natural Interpolation**: Use named placeholders (`{count}`, `{name}`) instead of string concatenation to preserve proper grammar and word order across languages.
