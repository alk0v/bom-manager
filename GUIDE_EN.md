# BOM Manager User Guide & Platform Manual

[🇺🇦 Українська версія (Ukrainian version)](GUIDE_UA.MD)

**BOM Manager** is a modern web application designed for electronic engineers, hardware R&D laboratories, and manufacturing workshops. The platform provides end-to-end inventory management for electronic components, hierarchical Bill of Materials (BOM) authoring, production batch runs, shortage tracking, procurement planning, and supplier order logging.

## 1. Key Platform Capabilities

- **Unified Component Catalog**: Centralized repository of microcontrollers, analog ICs, passives, connectors, and hardware modules with surface marking codes, package footprints, datasheets, photos, and live stock levels.
- **Bill of Materials (BOM)**: Real-time linkage between hardware projects and their component requirements, quantity per board unit, and circuit reference designators (`C1, R4, U2`).
- **Inventory Tracking & Shortage Detection**: Automatic calculation of component availability for planned manufacturing batches with soft red visual warnings for shortages.
- **KiCAD iBOM Integration**: Native parser for KiCAD Interactive HTML BOM files with intelligent part matching and catalog mapping.
- **Bulk CSV Import Wizard**: Multi-step wizard with automatic delimiter detection, intelligent category/footprint mapping, and duplicate resolution strategies.
- **Full Internationalization (i18n)**: 100% synchronized user interface in both English and Ukrainian with on-the-fly language switching.

## 2. Managing Hardware Projects & Bill of Materials (BOM)

The **Projects** section displays hardware design cards. Each card provides a board preview photo, project title, description, repository/documentation link, and active BOM item count.

![Projects Overview Screen](docs/screenshots/01_projects_view.png)

### 2.1. Working with Project BOM
Clicking the **"View BOM"** button opens the BOM management modal:
- **Component Breakdown**: Reference designators (e.g. `C1, C2, U1`), required quantities per device unit, and current warehouse stock.
- **Shortage Highlighting**: Rows with missing or insufficient inventory are automatically highlighted with a soft red background.
- **Adding Parts**: The **"Add Component"** button opens a catalog picker with multi-select category and footprint filters.
- **Attachments & Files**: Attach board schematics, Gerber archives, production instructions, and interactive HTML BOMs directly to the project.

![Project BOM Modal](docs/screenshots/02_project_bom_modal.png)

### 2.2. KiCAD Interactive HTML BOM (iBOM) Integration
BOM Manager natively supports importing `ibom.html` files generated by the KiCAD Interactive HTML BOM plugin:
1. Upload the `ibom.html` file to the project's attachments.
2. Click **"Import iBOM"**.
3. The system automatically parses all component values, footprints, and reference designators, matching them against existing catalog parts or offering 1-click part creation.

## 3. Batch Production & Inventory Stock Deduction

The **"Produce Project"** workflow records assembly runs and automatically recalculates inventory stock.

1. Within the project BOM modal or page, click **"Produce Project"**.
2. Enter the target batch size (the system automatically calculates the maximum producible quantity based on current stock).
3. Review the batch balance table:
   - Parts required for the entire run (`batchSize × requiredQty`).
   - Projected remaining stock after assembly.
   - Component shortages.
4. If shortages are detected, click **"Add Missing to Shopping List"** to send all deficit parts directly to procurement.
5. Confirming production atomically deducts the consumed components from warehouse storage locations.

## 4. Electronic Components Catalog

The **Components Catalog** offers high-performance search, multi-faceted filtering, and inline inventory management.

![Components Catalog](docs/screenshots/03_components_catalog.png)

### 4.1. Search & Filtering
- **Multi-Field Search**: Search across part numbers, surface markings, short summaries, and technical specifications.
- **Multi-Select Categories & Footprints**: Filter by multiple categories and packages simultaneously (e.g., both `SOIC-8` and `DIP-8`).
- **Mount Type Toggle**: Quick toggle between `All`, `SMD` (Surface Mount), and `THT` (Through-Hole).
- **Pin Count Range**: Filter components by minimum and maximum physical pin/pad count.
- **Stock Availability**:
  - Out of stock (`0`).
  - Below safety threshold (`≤ minQty`).
  - Low stock warning (Near to End).
  - In stock (`> 0`).

### 4.2. Inline Stock Editing
Current stock (`qty`) and minimum safety threshold (`minQty`) can be adjusted directly inside the catalog table without opening sub-dialogs: click the numeric field, type the new value, and press `Enter`.

### 4.3. Component Details Modal
Clicking on a component row opens a tabbed details view:
- **Overview & Specs**: Part number, marking code, datasheets, photos, and warehouse storage locations (bins, drawers, boxes).
- **Used in Projects**: Every hardware project BOM that uses this component, along with required quantities and reference designators.
- **Purchases & Pricing**: Comprehensive financial insights — weighted average unit cost, total amount spent, order history, and supplier URLs (Mouser, LCSC, AliExpress).

![Component Details Modal](docs/screenshots/04_component_details_modal.png)

## 5. Bulk Component Import from CSV

BOM Manager includes an import wizard for bulk uploading parts from spreadsheet exports and CSV/TSV files.

![CSV Import Wizard](docs/screenshots/05_csv_import_wizard.png)

### 5.1. Import Workflow
1. **Download Template**:
   - Click **"Download CSV Template"** in the step header bar.
   - The template is encoded in standard UTF-8 with Byte Order Mark (`\uFEFF`), ensuring non-ASCII characters and technical symbols open cleanly in Microsoft Excel.
2. **File Upload (Step 1)**:
   - Drag & drop your file into the upload zone or click **"Choose File"**.
   - Supports `.csv`, `.tsv`, and `.txt` files with automatic delimiter detection (comma `,`, semicolon `;`, tab `\t`).
3. **Category & Package Mapping (Step 2)**:
   - **Categories**: Automatically matches CSV category names against existing database records, or allows mapping to an alternative category, creating a new category inline, or skipping.
   - **Packages / Footprints**: Automatically resolves known footprints or allows creating new footprints with SMD/THT mount type and pin count configurations.
4. **Duplicate Strategy & Execution (Step 3)**:
   - **Skip Existing**: Existing components matched by part name are preserved without changes.
   - **Update Stock**: CSV quantities are added to existing catalog stock and allocated to warehouse storage bins.
   - **Create Duplicate**: Creates distinct separate entries for identical part names.
5. **Execution**: All operations execute within an atomic database transaction to prevent partial data corruption.

## 6. Procurement Shopping List

The **Shopping List** centralizes purchasing requirements and parts ordering.

![Procurement Shopping List](docs/screenshots/07_shopping_list.png)

- **Shortage Aggregation**: Parts automatically flow into the shopping list from project builds or can be added manually from the catalog.
- **Financial Estimations**: The system estimates total procurement cost based on recent order history.
- **Copy to Clipboard**: The **"Copy List"** button generates structured text with part numbers and quantities for quotation requests.
- **Recording Purchases**: Clicking **"Buy Component"** records unit pricing and supplier URLs, replenishing catalog stock and removing the fulfilled shortage from the shopping list.

## 7. Manufacturing Reports & Inventory Logs

The **Reports** section provides audit logs of all manufacturing activities and component movements.

![Production Reports](docs/screenshots/08_production_reports.png)

### 7.1. KPI Metrics
- **Active Units Produced**: Total number of successfully assembled devices across all active runs.
- **Parts Consumed**: Total component units deducted from warehouse storage.
- **Projects Produced**: Unique hardware designs manufactured.

### 7.2. Production Run Details & Rollback
Clicking **"Details"** on any production run displays the itemized list of consumed components, original stock levels, and deduction quantities.

If a production run was logged in error, the **"Cancel Production & Return Parts"** action automatically returns all consumed components back to catalog inventory.

![Production Run Details Modal](docs/screenshots/09_production_run_details_modal.png)

## 8. System Settings & Database Deployment

The **Settings** section configures system deployment and infrastructure parameters.

![Settings and Database View](docs/screenshots/06_settings_database.png)

### 8.1. Interface Language
Instant live switching between **English** and **Ukrainian** without requiring page reloads or server restarts.

### 8.2. Dual Database Engines
BOM Manager provides flexible database deployment options:
1. **SQLite 3 (Autonomous Mode)**: Zero-configuration self-hosted engine with Write-Ahead Logging (WAL). Ideal for single-user labs, local development, and standalone Docker containers.
2. **MySQL 8 / MariaDB (Centralized Mode)**: Enterprise networked database engine for multi-user engineering teams and centralized database servers.
3. **Diagnostics**: Live roundtrip latency benchmarks, connection pool status, and database entity counts.
